## 1. 属性与面板

### 1.1 属性点总量（每级 +5 存 StatePoint）
```text
总属性点 = 99 + (Lv - 1) * 5
```
来源：`totalStatPoints` / 原版 `ReformCharStatePoint`。1 级初始 99 点按职业固定分配（`INITIAL_STATS`）。

### 1.2 职业公式系数
每职业 6 系数 `{Life, Mana, Stamina, DamageMelee, DamageRange, DamageMagic}`：

| 职业 | Life | Mana | Stamina | DM | DR | DMG(F) |
|---|---|---|---|---|---|---|
| 武士 Fighter | 1 | 3 | 1 | 1 | 2 | 130 |
| 机械兵 Mechanician | 2 | 2 | 2 | 2 | 2 | 150 |
| 弓箭手 Archer | 3 | 3 | 2 | 3 | 1 | 190 |
| 枪兵 Pikeman | 1 | 3 | 1 | 1 | 2 | 130 |
| 魔枪兵 Atalanta | 2 | 2 | 2 | 2 | 1 | 150 |
| 骑士 Knight | 2 | 2 | 2 | 1 | 2 | 130 |
| 法师 Magician | 5 | 1 | 3 | 3 | 2 | 190 |
| 祭司 Priestess | 4 | 1 | 3 | 3 | 2 | 190 |
| 刺客 Assassin(=Archer) | 3 | 3 | 2 | 3 | 1 | 190 |
| 萨满 Shaman(=Magician) | 5 | 1 | 3 | 3 | 2 | 190 |

### 1.3 MaxHP（按职业 LifeFunction）
```text
f=1:  Lv*2.1 + (HEA*2.4 + STR*0.8) - 10
f=2:  Lv*2.1 + (HEA*2.2 + STR*0.6) - 5
f=3:  Lv*1.8 + (HEA*2.1 + STR*0.3)
f=4:  Lv*1.5 + HEA*2.1
f=5:  Lv*1.5 + HEA*1.9
```

### 1.4 MaxMP（按职业 ManaFunction）
```text
f=1: Lv*1.5 + SPR*3.8
f=2: Lv*0.9 + SPR*2.7
f=3: Lv*0.6 + SPR*2.2
```

### 1.5 MaxSP（通用）
```text
MaxSP = HEA*1.4 + (STR + TAL)/2 + Lv*2.3 + 80 + SPR
```

### 1.6 命中率 / 防御 / 吸收 / 负重
```text
命中(attackRating) = DEX*3.1 + Lv*1.9 + TAL*1.5
防御(defense)      = DEX/2 + TAL/4 + Lv*1.4
吸收(基础)         = Def/100 + Lv/10 + (STR+TAL)/40 + 1     (战斗实际含装备, 上限 80%)
负重上限(maxWeight)= STR*2 + HEA*1.5 + Lv*3 + 60
```

### 1.7 徒手攻击力（近战 DM=1 与其余两套）
```text
DM=1(近战):
  min = 1 + (STR+130)/130 + (TAL+DEX)/40 + 1
  max = 2 + (STR+130)/130 + (TAL+DEX)/35 + 1
其余:
  min = 1 + (STR+200)/200 + (TAL+DEX)/50 + 1
  max = 2 + (STR+200)/200 + (TAL+DEX)/45 + 1
```
近战伤害系数 F：`DM 1→130, 2→150, 3→190`（用于武器公式）。

### 1.8 移动速度档位（1~51，对标 wartale）
```text
档位 = int((TAL + HEA + Lv + 60) / 150.0 - 负重比 + 装备顶级 runSpeedMin) + 1
clamp [1, 51]
```
负重系统未实现，当前负重比恒 0。装备提速取所有装备 `RunSpeedMin` 最大值。

## 2. 移动速度：档位 → 每秒距离

```text
内部 MoveSpeed = 250 + 10 × 档位
步进@60fps = ((MoveSpeed × coeff) >> 8) / 256       [world]
每秒距离  = 步进 × 60                                [world/s]

walk: coeff = 180
run : coeff = 460
```
- 客户端 60fps 语义与服务端限速同源：`PlayerAction` 限速基准 = runSpeed(world/s) + 30% 容差 + 3.0 snap slack。
- 坐标缩放：`POSITION_SCALE = 256`（1 world = 256 内部步进，原版 fONE）。
- TICK_RATE = 20/s，TICK_MS = 50。

主循环：
```text
GameServer.tick() (20/s):
  monsterSpawnService.tick()
  movementService.tickPlayers()     → 消费客户端移动上报, 限速校验后应用+广播
  worldService.tick()               → 跨图检查
  regenerationService.tick()        → 每秒 HP/MP/SP 结算
```

## 3. 命中判定（Accuracy_Table，自 vs 自）

```text
ac = (攻方命中 - 防方防御) × 1.4
real = 查表(ac)                       # 区间取上界
命中率 = real - ((防方Lv - 攻方Lv) / 100.0) × 28
clamp [30, 95]
面板回避 = 100 - 命中率(自 vs 自, 等级修正 0)
```
查表边界：`ac < -190 → 50`；`ac > 2100 → 95`；其余查 `ACC_AC / ACC_PCT` 表 `{hit %, deflection %}`。

## 4. 每秒自动回复（原版 sinSetRegen，1 秒结算）

```text
HP恢复 = ((Lv + STR/2 + HEA)/180 + Σ装备HP再生) / 1.5
MP恢复 = (Lv + SPR*1.2 + HEA/2)/115 + Σ装备MP再生
STM装备= Σ装备STM再生                            # 再生取 min/max 均值, 精确 0.1
STM天生= 3.8 + Lv/7                            # InCreaSTM
STM总恢复 = Σ装备STM再生 + 3.8 + Lv/7
```
结算：整数部分每 1 秒落地（小数进累加器，满 1 才扣/加）；玩家死亡不回复；满值不推送。来源：`RegenerationService.settleOne`。

## 5. 跑步耐力消耗（原版 sinUseStamina）

```text
每秒消耗 DeCreaSTM = (1000 + 当前负重) / (最大负重 + STR/2 + 500) + 0.4
```
- 当前负重（背包未实现）按 0。
- `MovementService` 统计玩家 RUN 状态累计毫秒；`RegenerationService` 每秒把跑步毫秒折算成耐力扣减，与回复净额结算，SP 可扣到 0（原版 sp==0 强制走路判定）。
- 例（裸装权重恒 0）：STR 20 / MaxW 100 → `1000/(100+10+500)+0.4 ≈ 2.04/s`。

## 6. 战斗伤害（DamageCalculator / Svr_Damge）

### 6.1 玩家 → 怪物
```text
1. base = 技能伤害(>0 ? 技能 : 玩家攻击力)
2. 暴击: 暴击率 = 5 + (攻Lv - 怪Lv)*25/100, clamp [0,70]; 命中则 base × 1.7
3. (元素抗性 — 未实现, TODO)
4. base ×= (100 - 怪吸收率) / 100
5. 高等级怪保护: 若 怪MaxHP/4 < base 且 怪Lv > 玩家Lv
      → base = rand(怪MaxHP/8, 怪MaxHP/4)
6. 最终 = max(1, base)
```

### 6.2 怪物 → 玩家
```text
1. base = 怪攻击(Attack)
2. base ×= (100 - 玩家吸收%) / 100      # 含装备, cap 80
3. 格挡判定: 玩家装备格挡率(mid 累加, cap 50) 命中 → 0 伤害
4. base = max(1, base - 玩家防御)       # 防御含装备
5. 最终 = max(1, base)
```

### 6.3 玩家攻击力（有武器时覆盖徒手）
```text
min = 1 + wMin*(STR + F)/F + (TAL+DEX)/40
max = 3 + wMax*(STR + F)/F + (TAL+DEX)/40
实际 = rand(min, max+1)
```
F = 职业近战系数（§1.7）。

### 6.4 怪物承伤（Model）
```text
effective = max(1, damage - 怪防御/2)
```

## 7. 等级与经验

- 经验表来自 DB `characterexpdef`（`LevelExp`），启动时加载，`getExpForLevel(level)` 返回**达到该级累计经验**。
- 等级反算 `getLevelFromExp`：经验落在 `[expTable[L], expTable[L+1])` → L（对齐原版 GetLevelFromExp）。
- 服务器等级上限 `SERVER_LEVEL_MAX = 120`（经验表通常到 127）。

## 8. 怪物与视野

```text
怪物移动 step = speed(m/s) / 20 × 256（每 50ms tick）
  walk: 0.25 m/s → 3.2 /tick
  run : 0.50 m/s → 6.4 /tick   (IQ≥6 且有跑动动画)
```
- 追击朝目标直线方向，距离不足时 snap 到目标。
- AOI 广播用 DISCONNECT(1810) 而非 CONNECT(1086)：进入 1086~1810 环带的远端仍在可见集合，否则该区间玩家会停在最后一条 RUN 上"原地跑步"。

## 9. 属性分配 / 撤回

```text
加: 属性 += N, StatePoint -= N      (N = 1/10/100)
撤: 属性 -= N, StatePoint += N      (下限 属性 ≥ 1, 仅指定属性)
撤销最后1次分配: "undo" 命令走历史栈(最多回退 5 次 +1)
```
- 分配/撤回后重算 MaxHP/MP/SP 并 `persistStats` 落库，再回推 `S2C_PlayerState + S2C_CharacterStatus`。
- 来源：`PlayerService.allocateStat / deductStat / undoStat`。
